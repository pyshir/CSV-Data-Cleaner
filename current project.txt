## ১. Client Requirement (ক্লায়েন্টের চাহিদা)

ধরো, একজন E-commerce ব্যবসার মালিক তোমাকে ১,০০০ জন Customer-এর CSV ফাইল দিয়েছেন।

তার ফাইলে কিছু সমস্যা রয়েছে:

1. একই Customer একাধিকবার আছে।
2. কিছু Customer-এর Email Address নেই।
3. কিছু Email Address ভুল।
4. Name-এর শুরুতে ও শেষে অপ্রয়োজনীয় Space আছে।
5. Name-এর Capitalization ঠিক নেই।
6. Phone Number-এর মধ্যে অপ্রয়োজনীয় Space বা Special Character আছে।
7. কিছু Row-তে প্রয়োজনীয় তথ্য অসম্পূর্ণ।

ক্লায়েন্ট চান, তুমি একটি Python Script তৈরি করবে, যেটি স্বয়ংক্রিয়ভাবে এসব সমস্যা শনাক্ত ও সমাধান করবে।

## ৪. Data Cleaning Rules

ক্লায়েন্টের কাজ করার সময় নিজের ইচ্ছামতো Data পরিবর্তন করা যাবে না। তাই আমাদের Cleaning Rules আগে নির্ধারণ করতে হবে।

| Field       | Cleaning Rules                            |
| ----------- | ----------------------------------------- |
| customer_id | খালি রাখা যাবে না                         |
| name        | Extra Space Remove, Title Case            |
| email       | Lowercase, Space Remove, Regex Validation |
| phone       | শুধু Digit রাখা                           |
| city        | Extra Space Remove, Title Case            |

উদাহরণ:

| Before            | After             |
| ----------------- | ----------------- |
| `jahid hasan`     | `Jahid Hasan`     |
| `RAHIM AHMED`     | `Rahim Ahmed`     |
| `JAHID@GMAIL.COM` | `jahid@gmail.com` |
| `01712-345678`    | `01712345678`     |
| `01812 345678`    | `01812345678`     |

Phone Number-কে অবশ্যই String হিসেবে রাখবে, Integer হিসেবে নয়। কারণ বাংলাদেশের ফোন নম্বরের শুরুতে `0` থাকে।

Validation Rules:

- Empty Name → Invalid
- Empty Email → Invalid
- Wrong Email Format → Invalid
- Empty City → Warning, কিন্তু Row বাদ যাবে না।
- Duplicate Customer ID → Duplicate হিসেবে আলাদা শনাক্ত করবে।

আমরা প্রথমে Data Clean করব, এরপর Duplicate শনাক্ত করব, তারপর Validation করব।

## ৬. Project-এর ধাপে ধাপে Development Plan

3. Step 3: Duplicate Detection

   - Duplicate Row আলাদা রাখা।
   - Original Row সংরক্ষণ করা।
4. Step 4: Data Validation

   - Empty Name শনাক্ত করা।

5. Step 5: CSV Export

   - Duplicate Data আলাদা রাখা।
6. Step 6: JSON Report

   - Duplicate Records।

7. Step 7: Exception Handling & Logging
